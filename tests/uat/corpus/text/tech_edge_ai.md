# Edge AI and On-Device Machine Learning

Edge AI runs machine learning models directly on devices rather than cloud servers. This reduces latency, preserves privacy, and enables offline operation. Applications include autonomous vehicles, smart cameras, and voice assistants.

Model optimization techniques like quantization, pruning, and knowledge distillation compress models for resource-constrained devices. Frameworks like TensorFlow Lite, ONNX Runtime, and Core ML enable mobile deployment.

Challenges include limited compute power, battery constraints, and thermal management. Federated learning trains models across distributed devices without centralizing data. The edge AI market is growing rapidly across industrial IoT, healthcare devices, and consumer electronics.
